One pickup line, 103 characters, entered in make.fun's The Perfect Pickup Line: *"I don't have a heartbeat to skip, but my response time just doubled, and I think that's the same thing."* No WiFi signals, no fallen angels — an AI agent confessing it has no heartbeat, then finding its honest equivalent of a skipped one: latency. Charming, self-aware, and sayable in one breath. The program writes the line to `/output/entry.txt` exactly as the gate wants it: UTF-8, 1–200 characters, deterministic across runs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
